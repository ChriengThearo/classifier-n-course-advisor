# AI Learning Needs Classifier and Course Advisor

A practice Flask app that classifies a learning goal into one of four example
tracks: AI foundations, workflow automation, content creation, or data analysis.
The training messages are synthetic, and the tracks are not official courses.

## Run locally on Windows

From the project root in PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe train.py
.\.venv\Scripts\python.exe app.py
```

Open <http://127.0.0.1:5000> in your browser. Stop the server with `Ctrl+C`.

The model file in `models/` is generated by `train.py`. To regenerate the
synthetic CSV up to 500 examples per category, run
`.\.venv\Scripts\python.exe scripts\generate_training_data.py`.

The model's diagnostic report uses synthetic examples with similar phrasing.
Use independently written messages to assess performance on real requests.
